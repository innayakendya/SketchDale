A simple SketchDale Library for Multi Cloud Support.

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchDale.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SketchDale is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
